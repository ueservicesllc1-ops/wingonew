## 🎯 Configuración Mínima Necesaria

### 1. Crear proyecto Firebase
```
https://console.firebase.google.com/
→ Nuevo proyecto
→ Habilitar Auth + Firestore
```

### 2. Crear archivo .env
```env
VITE_FIREBASE_API_KEY=tu_key
VITE_FIREBASE_AUTH_DOMAIN=tu_domain
VITE_FIREBASE_PROJECT_ID=tu_id
VITE_FIREBASE_STORAGE_BUCKET=tu_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=tu_sender
VITE_FIREBASE_APP_ID=tu_app_id
```

### 3. Agregar eventos (en Firebase Console)
```javascript
Colección: events
{
  sport: "futbol",
  league: "La Liga",
  homeTeam: "Real Madrid",
  awayTeam: "Barcelona",
  startTime: "2025-10-15T18:00:00.000Z",
  status: "upcoming",
  odds: { home: 2.10, draw: 3.20, away: 3.50 }
}
```

## 🐛 Solución Rápida de Problemas

### Problema: Página en blanco
```bash
# Solución
1. Verifica que .env existe
2. Reinicia el servidor: Ctrl+C → npm run dev
3. Revisa consola (F12) para errores
```

### Problema: No hay eventos
```bash
# Solución
1. Ve a Firebase Console
2. Firestore Database
3. Agrega eventos (ver ejemplos arriba)
```

### Problema: No puedo apostar
```bash
# Solución
1. Asegúrate de estar logueado
2. Deposita fondos en tu perfil
3. Verifica que hay eventos disponibles
```
